Review the visual experience

Five pieces, all interactive. Start with the homepage and scroll slowly through the route story.

What is real, what is illustrative

  • Importer records are the app's demo seed dataset, snapshotted from the running API. They are illustrative, not real customs filings.
  • Calculations and outreach text come from a JavaScript copy of the app's Python logic, checked identical on 60 cost calculations and 20 outreach sequences.
  • Sea lanes are indicative passages, never vessel tracks. There are no live indicators, ratings or testimonials anywhere.
  • The bill-of-lading summary on the homepage is an illustrative sample built from the demo dataset.

How these were built

  • Static pages in prototypes/, served separately. The live app, its routes and its backend are unchanged.
  • The application prototype is generated from the saved Control Tower page by build_app.py, with the Meridian identity applied on top.
  • No new dependencies: the same d3-geo, topojson and world-atlas the app already loads.
  • Data tools (add buyer, CSV import and export) are switched off in the prototype.
